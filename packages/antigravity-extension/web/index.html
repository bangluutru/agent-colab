📘 AI Team Architecture & Developer Guide

1. Autonomous 3-Stage Orchestration

AI Team executes real software projects through a collaborative, adversarial loop where multiple autonomous AI agents fulfill specialized roles:

01
PLAN

Analyzes requirements, inspects project constraints, designs modular architecture, and outputs a structured plan.json schema.

02
BUILD

Initializes the workspace, installs dependencies, writes full production code, and builds automated test suites.

03
REVIEW

Independent, adversarial inspection of the Git diff. Detects regressions, logic bugs, edge cases, and issues APPROVED or CHANGES_REQUESTED.

2. Zero-Data-Loss Inter-Agent Protocol

Every decision, file write, review comment, and terminal command is recorded in an immutable append-only event stream (events.jsonl) within the run workspace. No state is lost across agent transitions.

1. Model-Agnostic Routing Principle

Stages are decoupled from specific AI vendors. You can freely assign any agent and any underlying model to any workflow stage:

  • Planner: Codex CLI (GPT-6 Astra), Gemini 3.8, or Claude Code CLI.
  • Builder: Gemini 3.8 Flash, Codex CLI, or Claude Code CLI.
  • Reviewer: Claude Code (Sonnet 5 / Opus 4), Codex CLI, or Gemini 3.8.
  • Fixer & Final Checker: Can auto-track Builder/Planner or be independently customized.

2. Built-in Team Presets

Preset Planner Builder Reviewer Ideal For
Recommended Codex · GPT-6 Astra Gemini · 3.8 Flash Claude · Sonnet 5 Full-stack production apps, balance of speed & quality.
Fast Delivery Gemini · 3.8 Flash Gemini · 3.8 Flash Claude · 3.5 Haiku Rapid prototyping, MVPs, quick scripts.
Deep Adversarial Codex · GPT-6 Astra Gemini · 3.8 Flash Claude · Opus 4 Mission-critical systems, security auditing, complex algorithms.

1. Command-Line Interface (CLI)

You can run autonomous team collaborations directly from your terminal:

# Start an autonomous run with default routing
npx tsx cli.ts --prompt "Build a responsive Markdown editor with live preview"

# Custom stage assignment
npx tsx cli.ts --prompt "Create a REST API" --planner gemini --builder gemini --reviewer claude

2. REST API Endpoints

Method & Path Description
POST /api/runs Initiates a new autonomous workflow run with user prompt & routing config.
GET /api/runs/:id Fetches detailed run state, review rounds, plan, and build status.
GET /api/runs/:id/stream Server-Sent Events (SSE) live stream for real-time progress and logs.
GET /api/status Probes readiness and CLI login status for Codex, Gemini, and Claude.
GET /api/models Returns available agent models and metadata.

1. Claude Code CLI Authentication

If Claude Code shows Blocked or Auth Unavailable, run the login command in your terminal:

claude auth login --email your_email@example.com

Once completed, click Verify / Recheck Auth in the Agent Cluster dialog or click the status footer in the sidebar.

2. Automatic Fallback Mechanism

When Auto Reviewer Fallback is enabled in Settings, the orchestrator automatically reroutes the review stage to OpenAI Codex if Claude Code is blocked or hits a rate limit, ensuring unbroken execution.
