AI Team — Multi-Agent Collaboration Protocol

A unified orchestrator uniting OpenAI Codex, Google Gemini, and Anthropic Claude into a continuous, adversarial engineering team.

⚡ 1. Autonomous 3-Stage Collaboration Flow

Instead of relying on a single prompt or single model, AI Team delegates work into specialized lifecycle roles with strict quality gates:

STAGE 01
PLAN

Architectural breakdown. Analyzes requirements, checks project constraints, formulates file structure, and emits a structured plan.json.

STAGE 02
BUILD

Physical construction. Initializes packages, writes source code, and creates automated test suites.

STAGE 03
REVIEW

Adversarial code review. Inspects git diff for regressions, edge cases, and safety vulnerabilities before approval.

Zero-Data-Loss Protocol

All agent activities, tool executions, and file diffs are appended to an immutable events.jsonl event stream in each run's isolated workspace directory. Nothing is lost across context transitions.

🔀 2. Model-Agnostic Routing Architecture

Stages are decoupled from specific vendors. You can freely assign any agent (Codex, Gemini, Claude) and any model to any role via the interactive UI popovers or team settings.

Team Preset Planner Builder Reviewer Use Case
Recommended Codex (GPT-6 Astra) Gemini (3.8 Flash) Claude (Sonnet 5) Balanced production applications with multi-vendor adversarial review.
Fast Delivery Gemini (3.8 Flash) Gemini (3.8 Flash) Claude (3.5 Haiku) Rapid MVPs, prototypes, and fast iterative workflows.
Deep Adversarial Codex (GPT-6 Astra) Gemini (3.8 Flash) Claude (Opus 4) Security-critical infrastructure, rigorous audit suites, and complex algorithmic tasks.

💻 3. Terminal CLI & REST API Reference

You can execute full collaborative workflows from your terminal or integrate via standard HTTP endpoints:

# Start an autonomous run with default configuration
npx tsx cli.ts --prompt "Build a real-time Markdown editor with live preview"

# Custom stage assignment
npx tsx cli.ts --prompt "Build a REST API" --planner gemini --builder gemini --reviewer claude

Key REST Endpoints

Endpoint Method Description
/api/runs POST Submit new prompt with custom routing to launch autonomous execution.
/api/runs/:id GET Fetch run status, logs, review rounds, and workspace metadata.
/api/runs/:id/stream GET (SSE) Real-time Server-Sent Events stream for live status updates.
/api/status GET Verify CLI and API connectivity for all connected agent engines.

🛠️ 4. Troubleshooting & Diagnostics

If Claude Code shows Blocked due to subscription auth, run this command in your terminal:

claude auth login --email haibangtran@gmail.com

After authentication is complete, click Re-probe All Agent Connections in the web settings drawer or status bar.
